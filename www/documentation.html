JRiver Media Center

Controls JRiver Media Center over its MCWS web interface. Browse and play music from any Navigator without a screen, and drive Media Center's own Theater View from the room remote when it is on a display.

Setup

  1. In Media Center, enable Options → Media Network and note the port (default 52199).
  2. Set the driver's JRiver Host and JRiver Port properties.
  3. Connect JRiver Virtual Switcher → HDMI OUTPUT to the AVR input the Media Center machine is plugged into. The internal links between the three proxies bind automatically.
  4. Use Test Connection to confirm the driver can reach Media Center; it logs the version and the available zones.
Network: every Navigator that displays album art fetches it directly from Media Center, not through the controller. On a segmented network each touchscreen and remote needs its own route to the Media Center host, not just the controller.

Browsing

The Artists, Albums and Playlists tabs map onto Media Center's own browse tree, and More opens the Audio node so Genre, Composer, Recent and anything else defined by Media Center's Browse Rules stays reachable. Change the rules in Media Center and the driver follows without modification.

Play All and Shuffle All appear on any item you drill into — an artist, a genre, an album — and play everything beneath it. They are not offered at the top of a tab, where they would mean the whole library.

Automation

The driver publishes read-only variables (Playing, Track, Artist, Album, Position, Duration, Shuffle, Repeat, Theater View, Connected and more), fires events for track changes, playback state, Theater View and connection loss, and accepts programming commands including Play Path and Play Playlist, which address content by name rather than by Media Center's internal IDs.

Composer lists the driver's programming under one of its device entries. That is cosmetic: these commands act on Media Center directly and work in either Listen or Watch mode, or with nothing selected. The transport each proxy exposes separately is what depends on the room's current selection.

Troubleshooting

Driver cannot reach Media Center. Confirm Media Network is enabled and test with curl http://<host>:52199/MCWS/v1/Alive.

Album art missing on one Navigator only. That Navigator has no route to the Media Center host. See the note above.

A remote key does nothing. Turn on Debug Mode and press it. Every unrecognised proxy command is logged once by name.

No progress bar on Now Playing. The driver broadcasts progress, but not every Navigator renders a progress bar; Halo Touch appears not to. Elapsed and total time are still available on the queue rows.
